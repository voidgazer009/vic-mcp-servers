## 1. 选题理由 · Why this topic

外贸业务员每天都在报价，而报价是最容易“算错就亏钱”的环节：CIF 保险基数错、利润率和加价率混淆、小单没摊固定费用、DDP 关税计税基数错、重货只按体积算柜。现有 AI 聊天直接算，结果不稳定、不可复查。把这些规则固化成确定性的工具，AI 只负责理解询盘和写回信。

## 2. 竞品检查 · Prior art (official MCP Registry, 2026-11-12)

| 搜索词 | 结果 |
|---|---|
| incoterm | 无 |
| quotation / export quote | 无同类（仅单一厂商询价、出口合规 HS 查询） |
| container | 有 3 到 4 个装柜 MCP（含 3D 装箱图，比我们更专业） |

**差异:** 本 Server 把“报价 + 术语 + 装柜 + 汇率”串成一条报价工作流，本地运行、免费、无需 API Key；装柜按航线柜价比推荐最省钱组合。3D 装箱不是我们的目标，需要时可与专业装柜 MCP 并用。

## 5. 实测发现并已修复 · Found and fixed during review

| # | 问题 | 修复 |
|---|---|---|
| 1 | 初版把目标利润率加在 EXW 上，导致 FOB 实际利润率低于目标（19.08%） | 改为 FOB 锚定，FOB 精确等于目标利润率 |
| 2 | 重货（瓷砖）推荐了 40HQ，但 40 尺限重比 20GP 还低 | 改成按柜价比搜索最省钱组合，重货正确推荐 3 x 20GP |
| 3 | 重货警告只在给出总箱数时才出现 | 改为始终提示 |
| 4 | `explain_incoterm` 输入 "FOB "（带空格）被拒 | 放宽长度并忽略大小写和空格 |
| 5 | 不支持的币种报错没说清是哪个 | 报错列出具体币种和全部支持币种 |
| 6 | 超高纸箱放不进 20GP/40GP 时没有提示 | 新增尺寸超限警告和改用开顶/框架柜建议 |
| 7 | server.json 描述超过官方 100 字符上限 | 缩短，已通过官方 schema 校验 |
| 8 | 柜型组合在 97% 以上满载时没有风险提示 | 新增“装载过紧”提示 |
